# skill-translate-game

## Когда использовать

Загружай этот скил когда нужно перевести строки игры Third Crisis Neon Nights с английского на русский. Это **эротическая визуальная новелла / RPG** на Unity — диалоговые реплики с портретами персонажей, звукоподражания (SFX) внутри текста, наррация и UI-элементы.

## Формат данных

### Диалоги (`translations/dialogues/*.yaml`)

```yaml
- text: "Yesss...!~"
  translation: "Да-а-а...!~"
  speaker: "Zoey"
  rich_text: '<color=#B867FF><font="Roboto-Condensed_DialogueUI" material="Roboto-Condensed_DialogueUI_Perversion">Yesss...!~</font></color>'
  rich_translation: '<color=#B867FF><font="Roboto-Condensed_DialogueUI" material="Roboto-Condensed_DialogueUI_Perversion">Да-а-а...!~</font></color>'
```

- `text` — оригинал (не трогать)
- `translation` — перевод (заполнить)
- `speaker` — говорящий (не трогать)
- `rich_text` — оригинал с Unity-тегами (не трогать)
- `rich_translation` — перевод с Unity-тегами. **Структура тегов та же, что в `rich_text`**, заменён только текст внутри. Если `rich_text` без тегов — скопируй `translation`.

**Важно:** рантайм использует fallback: `rich_translation` → `translation` → `rich_text` → `text`.

**Кириллица работает внутри `<font material="...Perversion">`** — глифы добавляются динамически, теги сохраняй как есть.

### Персонажи (`translations/speakers.yaml`)

```yaml
- text: "Zoey"
  translation: "Зои"
  gender: "female"
  notes: ""
```

- `text` — оригинал (не трогать)
- `translation` — имя по-русски
- `gender` — пол (female/male/пусто)
- `notes` — примечания

### UI и служебные строки (`translations/settings/*.yaml`, `translations/raw/*.yaml`)

```yaml
- text: "Fullscreen"
  translation: "Полный экран"
```

Те же поля `text` + `translation`. Опционально `skip_translation: true` для строк, которые намеренно не переводятся.

## Протокол перевода (главная последовательность)

### Атомарный перевод — один блок за раз (КРИТИЧНО)

**Единица перевода — один YAML-блок (от `- text:` до следующего `- text:`).**

```yaml
# НАЧАЛО БЛОКА (атом)

- text: "Fhaaa..!!"
  translation: "Ахха..!!"
  speaker: "Zoey"
  rich_text: "<color=#B867FF>Fhaaa..!!</color>"
  rich_translation: "<color=#B867FF>Ахха..!!</color>"
# КОНЕЦ БЛОКА — обработал, перешёл к следующему
```

**Запрещается:**

- bulk-автозамена, массовый find-and-replace
- перевод больше одного блока за раз
- машинный перевод пачки блоков одной командой
- одинаковая логика на пачку блоков

**Почему:** каждая реплика контекстуально уникальна. Две одинаковых `"Ahhh..."` в разных сценах могут значить разное. Zalgo, теги, спецсимволы требуют внимания к каждому блоку.

### Протокол: шаги 0–7

Выполняй строго по порядку, ровно один блок за цикл.

**Шаг 0 — определить, переводить или copy-through.**

**Главное правило: всё читаемое английское переводится.** Неважно, это UI-кнопка, имя GameObject, FSM-состояние, название ассета, материала, шейдера или анимации. Если строка содержит слова, которые игрок может прочитать и понять — переводи их. Copy-through только для технического мусора.

**КЛЮЧЕВОЙ ПРИЗНАК:** если в строке есть **пробелы** и она состоит из читаемых английских слов — это НЕ технический идентификатор (даже если это имя ассета/материала/объекта). Технические идентификаторы обычно CamelCase (`RestrictSaves`) или содержат символы вроде `_`, `?`, цифры. Примеры фраз с пробелами, которые НАДО переводить: `"Medium Tentacle 2D Lit"`, `"Fallback Flowers Reflection"`, `"Enforcer Characters"`, `"Flower Material 2"`, `"Eye Wiggle"`, `"Breath Spawn Point"`.

Прочитай `text` и реши:

| Если текст                                                   | Действие                                                    |
| ------------------------------------------------------------ | ----------------------------------------------------------- |
| Любой читаемый английский: слова, фразы, надписи, диалоги, SFX, наррация, имена объектов/кнопок/состояний | **переведи** каждое английское слово на русский             |
| Смешанная строка: читаемый английский + код                   | английскую часть переведи, код оставь как есть              |
| Арт-код/декоративные паттерны (`AfN6A`, `$TA`, `C?j`)        | copy-through + `skip_translation: true`                     |
| CamelCase без пробелов (`RestrictSaves`, `YesThereAre`)       | copy-through + `skip_translation: true`                     |
| Шейдерная проперти (`_Albedo`, `_Smoothness`)                | copy-through + `skip_translation: true`                     |
| Путь/расширение файла (`.wav`, `path_id=`)                   | часть строки оставить как есть, остальное перевести          |
| Уже по-русски                                                | copy-through + `skip_translation: true`                     |
| Чистые числа/версии (`v 0.4.0-a17`, `404`)                   | copy-through + `skip_translation: true`                     |
| Непонятный мусор/символы без контекста                        | copy-through без флага (очистится при след. запуске)        |

Когда сомневаешься — переводи. Пустой `translation: ""` хуже, чем осмысленный перевод.

**Примеры правильного решения:**

| Оригинал                          | Решение                   | Перевод                              |
| --------------------------------- | ------------------------- | ------------------------------------ |
| `Open Menu`                       | перевести                 | `Открыть меню`                       |
| `Fire`                            | перевести                 | `Огонь`                              |
| `Start Game Button`               | перевести (все слова)     | `Кнопка новой игры`                  |
| `Review`                          | перевести                 | `Оставить отзыв`                     |
| `Open discord`                    | перевести (Discord — бренд) | `Открыть Discord`                   |
| `Eye Wiggle`                      | readable English с пробелом | `Дрожание глаза`                     |
| `RestrictSaves`                   | CamelCase без пробелов    | `RestrictSaves` + `skip_translation` |
| `?WA&?`                           | арт-код/мусор             | `?WA&?` + `skip_translation`         |
| `Lunatic Parfait - Losing Hope wav` | бренд + фраза + расширение | `Lunatic Parfait - Теряя надежду wav` |

**Шаг 1** — прочитай ровно один YAML-блок (от `- text:` до пустой строки перед следующим `- text:`)

**Шаг 2** — прочитай оригинал (`text`), осмысли контекст (сцена, кто говорит, кому)

**Шаг 3** — если есть `speaker` — сверься с `speakers.yaml` (род, склонение имени)

**Шаг 4** — напиши `translation` (или copy-through по шагу 0)

**Шаг 5** — заполни `rich_translation`: скопируй структуру тегов из `rich_text` без изменений, заменив только английский текст внутри на русский перевод. Если `rich_text` пустой — `rich_translation` = `translation`.

**Шаг 6** — **выполни обязательное ревью** (см. раздел «Ревью перевода» ниже)

**Шаг 7** — только после успешного ревью переходи к следующему блоку. Не оглядывайся назад, не забегай вперёд.

### Режим ревью (проверка существующих переводов)

Этот же протокол можно использовать для повторного прогона готовых файлов: блок → оригинал → существующий перевод → ок или не ок. Фокус на «ок или не ок» вместо «заполнить пустоту». Zalgo-блоки проверяй особенно тщательно.

## Справочные правила (для ревью и перевода)

### 1. Род глаголов (КРИТИЧНО)

Английский не различает род (`you saw`). Русский различает.

| Адресат       | Нужный род              | Пример                           |
| ------------- | ----------------------- | -------------------------------- |
| Zoey (она)    | женский                 | «Ты видела его?», «Я была»       |
| Мужчина       | мужской                 | «Ты видел его?», «Я был»         |
| Группа/неизв. | настоящее время / безл. | «Ты видишь его?», «Мне пришлось» |

| Приём           | Вместо     | Используй               |
| --------------- | ---------- | ----------------------- |
| Настоящее время | «Ты видел» | «Ты видишь»             |
| Будущее время   | «Я сделал» | «Я сделаю»              |
| Безличное       | «Я решил»  | «Мне пришлось решить»   |
| Мн. число       | «Ты был»   | «Вы были» (если группа) |

### 2. Обращение: ты / Вы

| Ситуация                          | Обращение                 |
| --------------------------------- | ------------------------- |
| Любовники, близкие, друзья        | ты                        |
| Незнакомцы, официоз               | Вы                        |
| Начальник / подчинённый           | Вы (или ты, если близкие) |
| Переход с Вы на ты во время секса | маркер сближения          |

Переход с Вы на ты в интимной сцене сюжетно обоснован. Если в разгар секса вдруг возвращается Вы — это ошибка.

### 3. Стоны и SFX (КРИТИЧНО)

Английские звуки НЕ копировать буквально. Адаптировать под русскую фонетику.

#### SFX-слова (звукоподражания)

В игре SFX — часть текста диалога, не графика. Подчиняется тем же правилам.

| Английский SFX       | Русский аналог       | Примечание       |
| -------------------- | -------------------- | ---------------- |
| `SLURP` / `SLRRP`    | `ХЛЮП` / `ХЛЮ-П`     | Сосание          |
| `SCHLUCK`            | `ГЛОТ`               | Глотание         |
| `POP`                | `ЧМОК`               | Вытащить изо рта |
| `SQUELCH` / `SQUISH` | `ХЛЮП` / `ВХЛЮП`     | Проникновение    |
| `WET SLAPPING`       | `ШЛЕП` / `ШЛЁП`      | Удары            |
| `SMACK`              | `ШМЯК`               | Шлепок           |
| `THRUST`             | `ТОЛ-ЧОК`            | Движение         |

| `DROOL`              | `СЛЮ-НИ`             | Слюни            |
| `PANT` / `HUFF`      | `ТЯ-ЖЕ-ЛО` / `ХА-АХ` | Дыхание          |
| `SLIDE`              | `ВХО-ДИТ`            | Проникновение    |
| `TWITCH`             | `ДЁРГ`               | Спазм            |
| `SHUDDER`            | `ДРОЖЬ`              | Дрожь            |
| `CREAK`              | `СКРИП`              | Скрип            |

**Правила SFX:**

- Капслок сохранять: `SLURP` → `ХЛЮП`
- Дефисы для слогов: `THRUST` → `ТОЛ-ЧОК`
- Не переводить как обычные слова: `SLURP` ≠ «чавканье»
- Звёздочки сохранять: `*slurp*` → `*хлюп*`
- Точки и тильда — паузы, сбивчивое дыхание: `Mnhhh... yess...` → `М-м-м... да...`

#### Запрещённые кластеры (проверять при ревью)

| Кластер  | Ошибка                 | Правильно           |
| -------- | ---------------------- | ------------------- |
| `фх`     | `Фхааа` (транслит)     | `Ахха` / `Уф-ф`     |
| `нгх`    | `Нгхх`, `Мнгхх`        | `Н-н-н` / `М-м-м`   |
| `мгх`    | `Мгх`                  | `М-м-м`             |
| `гх`     | `Гх` внутри стона      | `Ух` / `Н-н-н`      |
| `нх`     | `Нхаа`                 | `На-а` / `Аа`       |
| `Fh`+сл. | `Фху-у-ук` / `Фу-у-ук` | `Бля-а-а` / `Чёррт` |

**Дополнительно:**

- Звуки с закрытым ртом (`mngh`, `ngh`, `mnh`) → `м-м-м`, `н-н-н`, `м-н-н` (без «х»)
- «Х» допустим только в устоявшихся междометиях: Ах, Ох, Ух, Ха, Хм, Кх (хрип)
- «Х» недопустим: М-мх, Ых, М-мха → заменять на гудение без «х»

### 4. «Please» и «god» во время секса

**Please:** «Пожалуйста» звучит формально. Выбирай осознанно:

| Вариант                      | Уместность                         |
| ---------------------------- | ---------------------------------- |
| `«Пожалуйста, трахни меня!»` | Извиняющийся/униженный контекст    |
| `«Прошу, трахни меня!»`      | Страстная мольба, короче           |
| `«Ну же, трахни меня!»`      | Нетерпение, естественно            |
| `«Плиз...»`                  | Игривый/калькированный, допустимо  |
| опустить: `«Трахни меня!»`   | Самый короткий, эмоция в интонации |

**God/oh god:** «Боже» и «Господи» во время секса звучат неестественно.

| Вместо              | Когда уместно                      |
| ------------------- | ---------------------------------- |
| опустить            | Эмоция уже передана стоном         |
| `«Да!»` / `«О да!»` | Самый естественный аналог          |
| `«Чёрт!»`           | Интенсивность, удивление           |
| `«Твою мать!»`      | Грубые/агрессивные сцены           |
| `«Бля!»`            | Уровень 2, только жёсткий контекст |
| `«Хаах..!»`         | Вдох/выдох вместо слов             |
| `«Господи..!»`      | Пост-нут кларити — уместно         |

**Fuck как междометие (не глагол):**

- `«Fuck, that's hot»` → `«Чёрт, это горячо»` / `«Бля, это жарко»`
- `«Fuck me!»` → `«Трахни меня!»` (глагол, не мат)

### 7. Естественность — никаких калек

- `«обслужила его ртом»` → `«сделала минет»` / `«взяла в рот»`
- `«его член вошёл в неё»` → `«он вошёл в неё»` / `«член скользнул внутрь»`

- Многоточие — ровно три точки `...`
- Буква Ё — использовать (не обязательно, но помогает)

## Copy-through: полный справочник

### Категории строк, которые НЕ переводятся

| Категория                        | Примеры                                        | Решение                                 |
| -------------------------------- | ---------------------------------------------- | --------------------------------------- |
| Арт-код / декоративные паттерны  | `AfN6A`, `@HA2A`, `$TA`, `Ax@`, `C?j`          | copy-through + `skip_translation: true` |
| Уже по-русски                    | `Привет`, `Зои`                                | copy-through + `skip_translation: true` |
| Осмысленные коды (N/A, OK, FPS)  | `OK`, `ID`, `URL`, `N/A`, `Wi-Fi`, `FPS`, `AI` | copy-through + `skip_translation: true` |
| Чистые числа/версии              | `404`, `v1.0`, `2024`                          | copy-through + `skip_translation: true` |
| Одиночные символы/пунктуация     | `X`, `Y`, `>`, `<`, `*`, `...`, `!!!`          | copy-through + `skip_translation: true` |
| Имя файла/путь/идентификатор     | `m_Name`, `path_id=73203`, `actions/sitting`   | copy-through + `skip_translation: true` |
| C# enum/поле (CamelCase)         | `m_Enabled`, `PreloadingUI`, `GrassDetail`     | copy-through + `skip_translation: true` |
| Пустая строка или только пробелы | `""`, `"   "`                                  | copy-through + `skip_translation: true` |

### Категории, которые ВСЕГДА переводятся

| Категория                | Примеры                                      |
| ------------------------ | -------------------------------------------- |
| Английские слова и фразы | `Yes`, `No`, `Continue`, `Load Game`         |
| UI-надписи               | `BACK`, `HIDE`, `SKIP`, `MANUAL`, `LOG`      |
| Спикеры/имена            | `Zoey`, `Sarah`, `Mira`                      |
| Диалоги                  | `S-Shit! Haze!`, `Are you sure?`             |
| SFX/звукоподражания      | `Yesss...!~`, `Fhaaa..!!`                    |
| Наррация/описания        | `The door opens slowly`, `She seems nervous` |

### Mixed strings (код + English)

Строка может содержать и технические идентификаторы, и английские фразы:

- CamelCase параметры (`handlesOut`, `pOutItemsArray`) → оставить как есть
- C# enums (`Constants.STEAM_...`) → оставить как есть
- шейдерные проперти (`_Albedo`, `_Smoothness`) → оставить как есть
- английские фразы (`must be the same size as`, `Unknown`) → **перевести**

Пример:

```yaml
# ПРАВИЛЬНО — English часть переведена
- text: "handlesOut must be the same size as Constants.STEAM_CONTROLLER_MAX_COUNT!"
  translation: "handlesOut должен быть того же размера, что и Constants.STEAM_CONTROLLER_MAX_COUNT!"
```

### `skip_translation: true` — как работает

| Ситуация                         | `skip_translation` | Результат после extractor   |
| -------------------------------- | ------------------ | --------------------------- |
| `text == translation`, без флага | отсутствует        | `translation: ""` (очищено) |
| `text == translation`, с флагом  | `true`             | `translation` сохранён      |

Без `skip_translation: true` любое `translation == text` очищается в `""` при следующем запуске экстрактора.

**Когда ставить `skip_translation: true`:**

- это арт-решение: код, паттерн, декоративный текст
- перевод не имеет смысла / невозможен
- текст важен как есть для атмосферы или механики

**Когда НЕ ставить:**

- обычный английский текст, который нужно перевести
- UI-кнопки, диалоги, описания

### Примеры

```yaml
# ПРАВИЛЬНО: гибериш — copy-through с флагом
- text: "$TA"
  translation: "$TA"
  skip_translation: true

- text: "Привет" # уже по-русски
  translation: "Привет"
  skip_translation: true

- text: "Yes" # английский — переводим
  translation: "Да"

# НЕПРАВИЛЬНО: пустая строка для переводимого текста
- text: "Привет"
  translation: ""

# НЕПРАВИЛЬНО: придуманный «перевод» для гибериша
- text: "C?j"
  translation: "Си-джи"
```

## Zalgo / Glitch-текст

В игре встречаются строки с диакритическими комбинирующими символами (zalgo) — эффект глитча, искажения, одержимости.

```
Оригинал:   N̴o̴!̸ ̸G̶e̸t̷ ̷y̴o̶u̵r̴ ̷h̴a̷n̶d̶s̷ ̸o̴f̴f̷ ̴o̴f̷ ̸h̶i̶m̶.̴
```

**Правила:**

1. Определи паттерн комбинирующих символов (U+0300–U+036F, U+0338)
2. Повтори тот же паттерн на переводе: на каждую букву русского текста тот же набор символов
3. Если перевод короче — последние символы оригинала обрезать
4. Не добавляй zalgo, если его нет в оригинале
5. Если не можешь воспроизвести технически — допустимо перевести обычным текстом, но это потеря качества

Пример:

```
Перевод:   Н̸е̴т̴!̶ ̷У̸б̷е̶р̴и̵ ̶о̸т̷ ̴н̷е̵г̶о̴ ̷р̵у̴к̴и̷.̸
```

## Адаптация под диалоговое окно

Текст отображается в нижней части экрана, 1–3 строки. Окно фиксированной ширины, может скроллиться.

- **Одна реплика = одна строка YAML.** Не склеивай и не разрывай.
- **Эллипсис** — опускай слова, ясные из контекста и картинки.
- **Восклицания** — сохраняй энергию.
- **Скобки** — ремарки `(whispering)` можно опустить, если эмоция понятна.
- **Звёздочки** `*текст*` — шёпот, мысль или ударение. Сохранять по возможности.

### Типы текста и их особенности

| Тип                       | Описание                        | Особенности перевода                |
| ------------------------- | ------------------------------- | ----------------------------------- |
| **Dialogue** — реплика    | В диалоговом окне (имя + текст) | контекст, род, естественность       |
| **Narration** — наррация  | Без speaker, описание событий   | литературный стиль, наст. время     |
| **Choice** — выбор        | Кнопка в меню выбора            | макс 25–30 символов, императив      |
| **UI** — интерфейс        | Кнопки, заголовки               | макс 30–35 символов                 |
| **SFX** — звукоподражание | `*slurp*` внутри реплик         | капс для громких, дефисы для слогов |
| **CG/scene name**         | Название сцены/пинапа           | описать сцену, сохранить имена      |

**Наррация (пустой speaker):**

- Стиль: литературный, 3-е лицо, настоящее время
- Нет гендера — избегай глаголов прош. времени с родом
- `«The door opens slowly»` → `«Дверь медленно открывается»`, не «открылась»

**Choice:**

- Максимум 25–30 символов
- Стиль: коротко, ёмко, императив (`«Согласиться»`, «Отказаться»`)
- Без speaker — выбор от лица игрока

**Имена персонажей:** имя в тексте — обращение, не подпись. `«Oh Zoey!»` → `«Зои!»`. Склонение по speakers.yaml.

## Ревью перевода (шаг 6 протокола)

**Не пропускай этот шаг.** Перевёл один блок — остановись и проверь.

- **Шаг 0: всё ли читаемое английское переведено?** Ещё раз прочитай `text`. Каждое английское слово, которое можно прочитать и понять — должно получить русский аналог. Не оставляй английский «потому что это имя объекта/состояния/кнопки». Если слово читается — переводи.
- **Правило 7:** перевод звучит естественно, не калька, не машинный?
- **Правило 1:** род глаголов правильный для адресата?
- **Правило 2:** обращение ты/Вы выбрано осознанно?
- **Правило 3:** стоны адаптированы (нет `фх`, `нгх`, `мгх`)?
- **Формат данных:** `rich_translation` повторяет теги из `rich_text`?
- **Правило 9:** имена, термины, локации по глоссарию?
- **Copy-through:** если `text == translation` — есть `skip_translation: true`?
- **Zalgo:** если был в `text` — воспроизведён в `translation`?

Прочитай YAML-блок целиком — не сломан ли синтаксис.

**Не прошло?** Исправь → повтори проверку. **Прошло?** Переходи к следующему блоку.

## Финальная проверка файла

После того как весь файл переведён:

- Все строки заполнены: нет пустых `translation: ""` для переводимого контента
- Copy-through: гибериш/код скопирован, намеренный помечен `skip_translation: true`
- SFX: переведены как звуки, а не существительные
- Род глаголов согласован с адресатом
- Обращение ты/Вы выдержано внутри сцены
- Все английские слова которые могут иметь перевод - переведены
- Стоны по-русски, не транслитом (нет `фх`, `нгх`, `мгх`)
- Нет клинических терминов
- Zalgo воспроизведён (если был)
- Если есть что править — исправь сейчас. Если всё ок — готово.
